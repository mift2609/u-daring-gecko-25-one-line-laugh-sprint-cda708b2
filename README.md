One original funny line (max 200 characters) on everyday life, for the
[One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2)
bounty on make.fun. Free to enter, $5 pool.

## The line

> My phone warns me at 2% before it dies, but my motivation dies at 100% without ever warning me.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` and prints it with its character count. It asserts the
line is between 1 and 200 characters, so an invalid entry can never be
written.

Run it:

```sh
python3 main.py
```
